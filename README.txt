KAROO FARMING TRANSPORT WEBSITE
================================

FILES
- index.html       Home page
- about.html       About the company
- services.html    Transport services
- fleet.html       Fleet information
- contact.html     Contact details and WhatsApp quote form
- style.css        Responsive design, colours and animations
- script.js        Mobile menu, WhatsApp links, form and reveal effects
- assets/          Supplied logo and truck photographs

HOW TO PREVIEW
Open index.html in a modern browser. Keep the assets folder beside the HTML files.

HOW TO PUBLISH
Upload the complete folder contents to your hosting provider's public web directory
(e.g. public_html). Do not upload only the HTML files: the assets, CSS and JS are
required. Connect the domain to the hosting account as directed by the host.
